# SWYNEX Power BI Retail Sales Dashboard

## Project Overview

This project is part of my Data Analyst Internship at SWYNEX.

The objective of this project is to build an interactive Power BI dashboard using a cleaned Retail Store Sales dataset. The dashboard provides insights into sales performance, transactions, product categories, payment methods, locations, and discount status.

## Tools Used

- Power BI
- DAX
- Python
- Pandas
- Matplotlib
- GitHub

## Dashboard KPIs

- Total Sales
- Total Transactions
- Average Transaction Value
- Total Quantity Sold

## Dashboard Analysis

The dashboard includes:

- Sales by Category
- Monthly Sales Trend
- Sales by Payment Method
- Sales by Location
- Top 10 Items by Sales
- Sales by Discount Status

## Interactive Filters

The dashboard includes slicers for:

- Transaction Date
- Category
- Payment Method

These filters allow users to interactively explore the sales data.

## Key Findings

- Total sales were approximately 1.64M.
- The dataset contains 12,575 transactions.
- Average transaction value was approximately 130.08.
- Online sales were slightly higher than in-store sales.
- Butchers generated the highest category-level sales.
- Item_25_FUR was the top individual item by sales.
- A small number of high-value transactions were identified during EDA.
